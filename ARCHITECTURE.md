# Architecture decisions

- EFI System Partition: 2 GiB FAT32.
- Root storage: LUKS2 over the entire second partition.
- Filesystem: Btrfs with separate root, home, snapshots, logs and pacman-cache subvolumes.
- Boot: systemd-boot and UKI generated by mkinitcpio.
- Authentication: LUKS passphrase at boot and a separate password for `operator`.
- Root password is locked; administration uses sudo.
- Desktop: Xorg + i3 started through `startx`; LightDM is intentionally absent.
- Dotfiles source: `https://github.com/daniilsolovey/dotfiles`.
- Additional repositories: volume-control-go, sensors-info-linux, cpu-monitoring and low-battery-notify.
- TPM2, Secure Boot signing and fingerprint authentication are deferred to later stages.

## v1.1 workstation decisions

- Browsers: Firefox and Chromium.
- Virtualization: VirtualBox host using modules matched to the standard Arch `linux` kernel.
- AUR: `yay` bootstrap followed by `cursor-bin` and the configured optional work applications.
- User groups: `wheel`, `audio`, `video`, `input`, `storage`, `docker`, and `vboxusers` when available.
